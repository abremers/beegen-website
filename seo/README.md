# SEO engine

Generator and validators for the SEO pages of beegen.co. Design and rules: `docs/seo-engine-plan.md`.

Generated pages (`comparar/`), `sitemap.xml` and `llms.txt` are built from the data in this folder. Never edit them by hand: validator 15 fails when a committed file differs from what the data renders.

## Setup

```
cd seo && npm ci                 # dev dependencies only (ajv, lighthouse, playwright)
npx playwright install chromium  # once, for the browser checks
```

A checkout of `abremers/beegen-platform` next to this repo (or `BEEGEN_PLATFORM_DIR=<path>`) lets `snapshot` and validator 5 read `src/lib/modules.ts`.

## Commands (from the repo root)

| Command | What it does |
|---|---|
| `node seo/cli.mjs snapshot` | Reads the platform registry into `seo/data/platform-snapshot.json`. The only source of Beegen prices and quotas. |
| `node seo/cli.mjs render` | Writes generated pages, `sitemap.xml` and `llms.txt`. Pure: no model call, no network. |
| `node seo/cli.mjs check [--offline] [--browser]` | Runs validators 1 to 18. `--browser` adds mobile layout and Lighthouse; `--offline` skips external link requests. Exits 1 on any failure. |
| `node seo/cli.mjs verify [--slug S]` | Lists claims that still need a direct fetch or a human check, with URLs and quotes. |
| `node seo/cli.mjs rehash --slug S` | After a claim or Beegen fact changes, re-read the page's prose and then record its new facts hash. |
| `node seo/cli.mjs approve --slug S --as founder\|lawyer --by "Name"` | Records an approval of the page's current content (hash of `<main>`). Any later change voids it. |
| `node seo/cli.mjs index --slug S` | Flips a page to `index, follow` and adds it to the sitemap and `llms.txt`. Refuses unless both approvals match and every claim is verified. |

## Where things live

| Path | Contents |
|---|---|
| `data/competitors.json` (+ `.schema.json`) | Competitor claims with source URL, access date and evidence method. |
| `data/site.json` | Module availability (the one-line switch for "próximamente"), Beegen claims quoted from `pricing.html` or platform docs, hub settings. |
| `data/platform-snapshot.json` | Generated by `snapshot`. |
| `data/static-pages.json` | Hand-written pages listed in `sitemap.xml`. |
| `data/approvals.log.json` | Append-only approval and index log. |
| `content/comparar/<slug>.json` (+ `data/content.schema.json`) | The page's written prose; every sentence lists the facts it rests on. |
| `templates/` | Nav and footer copied from the site, and the base of `llms.txt`. |

## Verifying a claim

Open the source URL, find the quote, then add an evidence item with `"method": "direct_fetch"` (fetched by a tool) or `"human_check"` (a person looked), today's `accessed_at` and the exact quote, and set `"status": "verified"`. Never upgrade evidence nobody obtained. If the page no longer says it, set `"status": "removed"`.
